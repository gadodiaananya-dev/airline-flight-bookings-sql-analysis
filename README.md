Airline Flight Bookings

An end-to-end data analytics project on an airline bookings database. Seven raw CSV files are cleaned and validated in Python (pandas), loaded into MySQL, and analyzed with 25 SQL queries covering filtering, aggregation, joins, subqueries, CTEs, views and window functions. Results are presented in a 28-slide deck.

Project Overview

Airlines generate large volumes of connected data across flights, bookings, tickets and fares. Reading these tables by hand is impractical. This project uses SQL to turn them into measurable insights on:

Revenue and fares: how much is earned, and by which fare class
Airports and routes: which departure airports and routes perform best
Flight scheduling: monthly flight volume, flight durations, and status mix
Passenger behavior: check-in rates and booking patterns

Scale: 7 tables, 17,510 rows, 900 flights, 15 airports, 3,000 bookings, 4,805 tickets and 6,258 flight segments, all from 2025.
